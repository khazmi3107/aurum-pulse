Kebutuhan agar signal benar-benar real-timeLANGKAH BERIKUTNYA
  1. TradingView chart widget: menampilkan grafik live/tertunda sesuai simbol, paket, dan penyedia. Widget embed umumnya tidak menyediakan OHLC candle untuk dibaca langsung oleh JavaScript website.
  2. Data feed / API: backend harus menerima OHLCV real-time dari broker atau vendor data yang mengizinkan penggunaan XAUUSD. Akses data, biaya, batas request, dan izin redistribusi tergantung penyedia.
  3. Signal service: backend menghitung EMA, RSI, MACD, ATR, struktur M15/M5/M1, lalu hanya mengeluarkan BUY/SELL saat aturan terkonfirmasi; selain itu WAIT.
  4. Notifikasi posisi: backend dapat mengirim alert browser/Telegram saat sinyal baru muncul, beserta harga entry, SL, TP, waktu candle, dan alasan. Alert harus menunggu candle close dan pemeriksaan spread.
  5. Output terverifikasi: sertakan timestamp candle terakhir, sumber feed, spread, entry, SL, TP, rasio risiko/imbalan, dan alasan signal.
  6. Keamanan: simpan API key di server, bukan HTML browser. Untuk eksekusi order otomatis diperlukan integrasi broker terpisah dan pengujian menyeluruh.
